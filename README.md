# Python Bank 💳

My first Python banking project.

A console banking application created with Python.

## Features

- User registration
- User login
- Balance checking
- Deposit money
- Withdraw money
- Transfer money between users
- Transaction history
- Data saving with JSON

## Technologies

- Python 3
- JSON
- File handling
- Functions
- Lists and dictionaries

## How to run

1. Clone the repository

2. Make sure Python is installed

3. Run:
python script6.py


## Project structure

Python-Bank

script6.py # Main program 
users.json # User database (created automatically) 
README.md
